# Fonts

- `Vazirmatn-Variable.woff2` — Vazirmatn by Saber Rastikerdar, SIL Open Font
  License 1.1 (from the `vazirmatn` npm package, v33).
- `Anjoman-*.ttf` — headings, supplied with the "BDC Yazd" design handoff on
  2026-10-01. The web-embedding license for Anjoman must be confirmed by the
  center before launch (OQ-BD-17). To fall back to Vazirmatn everywhere,
  remove `anjoman` from `src/app/fonts.ts` and `src/app/layout.tsx`.
