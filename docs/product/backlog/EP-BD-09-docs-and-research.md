# EP-BD-09 · مستندات، برنامه‌ریزی و پژوهش

هر چیزی که ادامهٔ کار را بدون حافظهٔ یک نفر ممکن می‌کند: یادداشت تحویل،
تصمیم‌های معماری، روال کار، همین بک‌لاگ و پژوهش.

### ST-BD-09-02 · روال شاخه، PR و بازبینی مستقل
